# Contributing to Eventide

Thank you for considering a contribution.

## Before submitting code

- Only submit work that you have the right to contribute.
- Preserve the repository's license files, `Required Notice:` lines, and SPDX metadata.
- Preserve existing `SPDX-FileCopyrightText` lines when modifying files. For new text files, identify the actual copyright holder and add the project's `SPDX-License-Identifier`; for files that cannot contain comments, add a matching `.license` companion file.
- Run the tests and `reuse lint` before opening a pull request.

## Contribution licensing

By submitting a contribution for inclusion in Eventide, you confirm that you have the right to submit it and agree to make it available under the same `PolyForm-Noncommercial-1.0.0` terms as the repository, unless separately agreed in writing.

You retain copyright in your contribution. This document does not assign that copyright or grant the maintainer separate commercial relicensing rights. Open an issue before substantial work; the maintainer may request a separate contributor agreement before accepting a contribution that would affect the project's ability to offer commercial permissions.
